# 网易云音乐 Lite（第三方客户端）

> ⚠️ **仅供个人学习研究使用**：本项目不上架、不分发、不用于任何商业用途。
> 项目**不包含任何 VIP 破解 / 付费绕过**逻辑：歌曲能否播放、音质档位完全取决于你自己账号的实际权限。
> 所有音乐内容、数据与接口版权均归网易云音乐所有，请支持官方客户端。

一个使用 **Kotlin + Jetpack Compose (Material 3)** 实现的网易云音乐精简版 Android 客户端：
单 Activity、多模块、MVVM 架构，**直连网易云官方 Web 接口（weapi / eapi）**，无需自建后端服务。

## 功能一览

### 1. 登录
- 手机号 + 密码登录、手机号 + 短信验证码登录（倒计时、错误提示）
- 二维码扫码登录（本地生成二维码 → 轮询确认 → 自动登录）
- 游客模式：未登录也可浏览首页、听免费歌曲
- 自动登录（Cookie 持久化到本地 DataStore）、退出登录
- 登录状态 / 用户信息获取、等级（Lv.）展示

### 2. 发现页（首页）
- 推荐歌单、推荐新音乐
- 每日推荐（30 首）→ 独立列表页
- 私人 FM（喜欢 / 不感兴趣 / 下一首）
- 排行榜（官方榜 + 更多榜）
- 歌单广场（分类筛选 + 分页加载）
- **下拉刷新**：整页重新拉取推荐歌单 / 新歌 / 榜单 / 歌单广场第一页（失败时保留原内容，不打断浏览）
- 顶部搜索入口

### 3. 搜索
- 实时搜索建议（防抖请求，点击建议直接发起搜索）
- 分类搜索：单曲 / 歌手 / 专辑 / 歌单 / 用户（cloudsearch）
- 搜索结果单曲行直接展示封面，点击播放
- 结果里的**专辑行可点进专辑详情**（歌手行 / 用户行同样可点）
- 搜索历史（本地保存、单条删除、一键清空）

### 4. 歌单
- 歌单详情：封面 / 创建者 / 播放量 / 标签 / 简介 / 歌曲列表
- 播放全部、随机播放
- 收藏 / 取消收藏歌单
- 新建歌单、添加歌曲到歌单
- 我喜欢的音乐、我创建 / 我收藏的歌单
- 单曲红心（全局状态同步，任意页面可点）

### 4.1 专辑
- 专辑详情：封面 / 专辑名 / 歌手（可点进歌手页）/ 发行日期 / 曲目数 / 唱片公司
- 播放全部、逐曲播放、红心、下一首播放 / 添加到播放队列
- 单曲菜单支持**分享歌曲**（系统分享面板）与**复制链接**
- 入口：搜索结果「专辑」tab、歌手页的专辑列表

### 5. 播放器（核心）
- 播放 / 暂停 / 上一首 / 下一首；自绘细进度条（点击 / 拖动跳转，圆点滑块）
- 播放页底部两排控制：上排点赞 / 评论 / 音质 / 倍速 / 加入队列，下排播放模式 / 上一首 / 播放 / 下一首 / 目录
- **目录面板**（右下角）：播放队列（含数量）、歌词翻译开关、播放设置（定时停止 / 均衡器）、**分享歌曲 / 复制链接**
- 播放模式：列表循环 / 单曲循环 / 随机播放 / 顺序播放
- 播放队列：查看 / 单曲移除 / 清空 / 点击切歌
- 倍速播放 0.5x ~ 2.0x（`setPlaybackParameters` 保持音调，全局记忆）
- 音质切换：标准 / 较高 / 极高 / 无损（实际以账号权限为准）
- **定时停止播放**：15 / 30 / 45 / 60 / 90 分钟，到时自动暂停，顶栏实时倒计时
- 歌词：LRC 解析、逐行滚动并**精确垂直居中**（整段定位只做一次 420ms 平滑动画，没有「先滚再修正」的顿挫）、
  点击某行跳转进度；**点歌词区空白处返回封面**（没有歌词时点空白同样能回封面），点封面切回歌词
- **歌词翻译开关**：收进右下角「目录」面板，一键显示 / 隐藏逐行翻译（全局记忆）
- **锁屏 / 通知栏歌词**（默认开，设置里可关）：系统媒体卡片只能显示「标题 + 一行副标题」，
  这里把副标题（原歌手名）换成当前这一句歌词，跟着播放逐句刷新；
  按**整首歌最长的一句**预先判断要不要占两行：长句在标点 / 空格处断开、短句补空行，
  保证切句时卡片高度不跳（两行仍放不下时第二行以省略号截断）；
  刷新只改会话展示用的元数据、不重新加载音频，所以不会打断播放
- 点顶部歌手名直接进入**歌手页**（歌手头像 / 简介 / 热门歌曲 / 专辑）
- 播放打卡上报（播放达标后自动 scrobble）
- Mini 播放条 + 全屏播放页（上滑展开 / **手指下滑跟手收起**：拖过约 1/4 屏或快速下甩即收起，否则弹回原位）
- **长按封面**进入全屏看图（可把高清封面保存到相册，保存后系统 Toast 提示「已保存到相册」）
- **播放页背景**：用封面主色铺一层「上彩下暗」的渐变底（换歌时颜色渐变过渡），不再是一片纯黑 / 纯白；
  深色主题压暗成深色调，浅色主题只加一层很浅的色调，保证文字始终清楚
- **灵魂鼓点闪光**（设置里可开，默认关）：开启后播放页切到「黑舞台」（四周黑、中间光源），
  用封面主色做背景光晕，随低频鼓点**律动闪烁**——
  拍点亮起、拍间淡出（起拍约 50ms 贴着鼓点亮、回落约 0.25s，抬升 0.12 就算满格，轻鼓点也能触发）；
  封面保持静止，只有光晕在呼吸；
  深色主题是「黑舞台」（四周黑、中间光源），浅色主题保持浅色底、把光晕收敛成一层彩色呼吸（文字仍是深色）；
  需要录音权限读取播放音频频谱（仅本地分析、不录音不上传），无权限 / 设备不支持时自动退回模拟节拍
- **细腻动效（跟手）**：二级页右滑推入 / 返回反向（带视差与淡入），一级 tab 之间淡入缩放不横推；
  封面 ↔ 歌词小距离滑动 + 淡入淡出；进度条与时间由「500ms 一跳」改为线性补间连续滑行，
  拖动时滑块 / 轨道变粗、松手立即归位；播放键按下回弹、播放 / 暂停图标淡入切换、爱心点亮回弹 + 颜色渐变；
  「正在播放」图标轻轻呼吸、底部 tab 选中色渐变并微放大；歌单卡片按下缩一下、封面换图淡入淡出、
  加载 / 空 / 错误态淡入
- 歌曲下载：按当前音质（含无损）保存到本地，下载完成后离线播放
- 系统集成：通知栏 & 锁屏媒体控制（Media3 MediaSessionService，需系统允许通知）、耳机线控 / 系统媒体键、音频焦点自动暂停
- 后台保活：`stopWithTask=false` + 网络唤醒锁（`WAKE_MODE_NETWORK`），设置页提供「后台播放保护」入口申请电池优化白名单

### 6. 均衡器
- 系统级 5 段均衡器（Android `Equalizer`，挂载到当前播放音频会话，实时生效）
- 预设：平直 / 流行 / 摇滚 / 低音增强 / 人声 / 高音增强
- 各频段增益滑条（dB 实时显示）、一键全部重置
- 开关与频段参数本地持久化，重启后保留

### 7. 评论
- 精彩评论 + 最新评论分组展示、分页加载
- 评论点赞 / 取消点赞
- 发表评论、回复评论、删除自己的评论
- 评论项：头像 / 昵称 / 时间 / 内容 / 点赞数 / 楼中楼（被回复内容展示）
- **长按评论内容复制到剪贴板**（Snackbar 提示「已复制评论」）
- 点评论头像 / 昵称进入对应用户主页
- 评论者昵称旁展示 VIP / SVIP 标识

### 8. 我的
- 个人资料：头像 / 昵称 / 签名 / 关注数 / 粉丝数 / 等级 / **VIP·SVIP 标识**
- 我的消息（私信会话列表，未读角标）
- 我的关注 / 我的粉丝（独立列表页）
- 我喜欢的音乐、**最近播放（本地记录，独立页面）**
- **我的下载**（已下载歌曲列表，支持播放与删除本地文件）
- 听歌排行（最近一周 / 所有时间）
- 我创建 / 我收藏的歌单
- 退出登录

### 9. 用户与私信
- 用户主页：头像 / 昵称 / 签名 / 关注数 / 粉丝数 / 等级 / VIP 标识、TA 的歌单、私信入口
  （**关注数 / 粉丝数可点击**，进入对应的关注 / 粉丝列表）
- 私信会话列表：对方头像 / 最后一条消息 / 相对时间 / 未读数
- 会话列表停留时**每 8 秒静默刷新**；聊天页停留时**每 5 秒轮询最新消息**（官方私信无推送 / 已读接口）
- **本地已读记录**：打开会话后按消息时间记录已读位置（DataStore 持久化），已读会话不再显示未读角标

## 架构说明

### 网络层：直连官方接口
- `:core:network` 内自行实现了网易云 Web 端请求加密（AES-128-CBC 双层加密 + RSA），
  对应官方 `https://music.163.com/weapi/...` 接口；播放地址与评论写操作使用
  `https://interface.music.163.com/eapi/...`（eapi，模拟移动端请求头 / UA / Cookie）。
- Cookie（`MUSIC_U`、`__csrf` 等）登录后持久化到 DataStore，请求自动携带；
  写操作（点赞、评论等）需要 `__csrf`，实现中统一附加。
- 接口路径全部以 Retrofit 方法集中定义在 `NeteaseApi.kt`，便于后续接口变动时替换。

### 播放器
- `PlaybackController` 单例封装 ExoPlayer：播放队列、播放模式、倍速、音质、URL 解析、
  歌词加载、播放打卡；`NcmusicPlayerService` 提供 MediaSessionService 通知栏 / 锁屏控制。
- 媒体通知细节：`MediaSessionService` 只有在存在「服务型」`MediaController` 客户端连接
  （绑定服务 → `onGetSession` → `addSession`）时才会启用通知管理器；界面直接驱动 ExoPlayer，
  因此服务内用服务型 `SessionToken` 保持一个常驻控制器连接，通知栏 / 锁屏 / 系统媒体键因此可用。
- 播放地址通过 `/song/enhance/player/url/v1` 按音质请求，返回 `url == null` 或错误码时
  做兜底提示（如 VIP 歌曲 `-110`）。

### 分页
- 未引入 Paging3，统一采用 `offset / limit` 手写分页 + "加载更多"（见下文偏差说明）。

### 多语言
- 界面文案集中在 `core:common/src/main/res/values*/strings.xml`：`values/` 为英文默认，
  `values-zh/` 简体中文、`values-zh-rTW/` 繁体中文，另有日语 / 韩语 / 西班牙语 / 法语 / 德语 / 俄语。
- `LanguageManager` 在 Application / Activity 的 `attachBaseContext` 中包装语言配置；
  设置页切换后写独立 SharedPreferences 并 `recreate()`，无需重启应用。默认跟随系统，
  系统语言不在支持列表时回退英文。
- 大数字（播放量 / 粉丝数）按语言选择单位：中文用「万 / 亿」，繁体用「萬 / 億」，
  其它语言用 K / M / B。

### 下载
- 下载任务由 `PlaybackController` 解析出播放地址后交给 `DownloadManager` 写入
  `Android/data/com.ncmusic.lite/files/downloads/`；元数据（歌曲名 / 歌手 / 封面 / 音质 /
  文件路径）以 JSON 形式存在 DataStore，供「我的下载」列表与离线播放使用。
- 播放时优先命中本地路径（`PlaybackController.localPaths`），文件不存在则回退在线地址。

## 与原始提示词的偏差说明

1. **不使用自建 NeteaseCloudMusicApi 后端**（按需求改为直连官方接口）：
   原提示词以 binaryify/NeteaseCloudMusicApi 作为本地服务；本项目直接在客户端内实现
   weapi/eapi 请求加密与 Cookie 管理，无需部署任何后端，开箱即用（前提是网络可达网易云服务器）。
2. **分页未使用 Paging 3**：为保持接口失败兜底简单可控，统一手写分页。
3. **底部导航精简为 2 个 tab：发现 / 我的**（按实际需要移除了播客占位页），
   且只显示横向文字标签（无图标，选中项用主色 + 半粗字重）。
4. **设置页未提供 BaseURL 配置项**：直连官方域名，无需配置。
5. **部分可选增强未实现**：MV 播放、播客 / 电台、云盘、听歌识曲、一起听、动态 feed、
   桌面小组件、车载模式；歌单内搜索、评论楼中楼展开也未做。
   私人 FM 目前是「取一批就播」，没有独立 FM 页与喜欢 / 不感兴趣按钮。
6. **歌单管理**：已支持新建歌单、收藏 / 取消收藏、添加歌曲；重命名 / 删除 / 歌曲排序
   的接口已在 `PlaylistRepository` 中封装，UI 暂未接入。
7. **均衡器**：依赖系统 `android.media.audiofx.Equalizer`，需要在**播放开始后**进入
   均衡器页挂载频段（音频会话就绪后才有频段列表）；不同设备的频段数量 / 中心频率
   由系统决定（模拟器与部分设备上可能不支持）。
8. **私信**：发送走移动端 eapi 通道；官方无删除消息 / 已读上报接口，因此聊天页仅支持发送与查看，
   实时性用页面内轮询模拟（会话列表 8 秒、聊天页 5 秒），未读角标用本地已读时间抵消。
   本地回显的消息和服务端回显按**展示文本**做一对一替换（服务端回显是 JSON 富文本，
   逐字比对会把同一条消息留成两条）。

## 编译与运行

```bash
# 1. Debug 包（带 Compose 调试工具，体积大，仅开发用）
./gradlew :app:assembleDebug          # Windows: gradlew.bat :app:assembleDebug
#    app/build/outputs/apk/debug/app-debug.apk

# 2. 发行包（R8 混淆 + 资源裁剪 + 字体子集化，当前约 4.2 MB）
./gradlew :app:assembleRelease
#    app/build/outputs/apk/release/app-release.apk

# 3. 安装到设备（发行包与 Debug 包同签名，可直接覆盖安装、保留登录态）
adb install -r app/build/outputs/apk/release/app-release.apk

# 4.（可选）运行单元测试（LRC 解析、weapi 加密、锁屏歌词排版）
./gradlew test
```

发行包做了这些体积 / 安全处理：

- `minifyEnabled` + `shrinkResources`：R8 混淆裁剪，未使用的类、资源、多语言字符串都会移除；
- 只打包 `arm64-v8a` / `armeabi-v7a` 真机 ABI，以及简中 / 繁中 / 英 / 日 / 韩 / 西 / 法 / 德 / 俄资源；
- 移除了未使用的 `media3-exoplayer-hls`（只播网易的 MP3 / FLAC 直链）；
- 内置 PingFang Bold 做了**常用字子集化**（GB2312 + 符号，约 2.3 MB，原文件 10.9 MB），
  生僻字会按字形自动回退到系统字体；
- 沿用本机 Debug 证书签名（个人使用，保证能直接覆盖安装旧包；对外分发请自行换正式签名）。

首次运行：进入「我的」→ 登录 / 注册，可用**手机号验证码 / 密码 / 扫码**任一方式登录
（本 App 不内置任何账号，请使用自己的账号）。体验游客模式可直接浏览首页并播放免费歌曲。

## 已知问题

1. **写操作风控**：点赞歌曲 / 评论、发评论等属于登录态写操作，网易侧存在风控机制。
   触发后接口可能返回 `-460`（IP 频控）或 `250`（要求移动端通道）等错误，通常稍后自动恢复；
   本项目已为各写操作选择正确的通道（如评论写操作走移动端 eapi，红心走 `song/like`），
   若仍失败，等待一段时间后重试即可。
2. **关注 / 取关被安全验证拦截**：网易对「关注」这类写操作会做账号级风控。若账号被判定需要安全验证，
   接口返回 `code: -462` 与 `verifyType 20`，并给出验证地址（`st.music.163.com/encrypt-pages`）。
   此时应用会弹出「需要安全验证」对话框，并提供「去验证」按钮打开该地址——
   该验证（绑定手机号 / 短信验证）**只能在浏览器或官方 App 中完成**，第三方客户端无法代做；
   完成验证后回到本应用重试关注即可。单独的「取消关注」不受影响。
3. **VIP / 付费歌曲**：播放接口返回 `-110`，应用会明确提示「该歌曲需要 VIP 权限」，
   不做任何绕过。
4. **音质档位**：实际返回音质以账号权限与版权方提供为准，无权限时会自动降到可用的档位。
5. **私人 FM**：接口单次返回一批歌曲，列表到底后需手动继续加载。
6. **接口时效性**：所有接口均为逆向自官方 Web / 移动端实现，官方调整后可能失效；
   接口集中定义、便于维护替换。
7. **搜索建议接口**：官方建议接口返回的歌曲不含封面字段；由于点击建议的行为是
   "发起搜索"（随后由 cloudsearch 提供完整数据），不影响实际播放与封面展示。
8. **私信实时性**：官方没有开放推送通道，也不提供「标记已读」接口，因此会话列表 / 聊天页
   采用可见时轮询（8s / 5s）；未读数由「服务端未读数 + 本地已读时间」共同决定，
   清除缓存或重装后本地已读记录会丢失。
9. **通知栏媒体卡片**：依赖系统允许应用发送通知；若在系统设置中关闭了通知权限，
   通知栏不会出现媒体卡片（锁屏与系统媒体键控制不受影响）。
   媒体卡片的**进度条由系统 SystemUI 绘制**，第三方无法改变其形状（做不成波浪形），
   因此本项目不在通知栏额外叠加自定义进度通知（避免与系统媒体卡重复）；
   播放页的进度条也保持普通细直线（不做波浪形），点击 / 拖动均可跳转。
   （历史版本留下的「播放进度（波浪）」通知频道会在播放服务启动时自动删除。）
10. **用户等级来源**：等级取 `user/detail` 响应的顶层 `level` 字段（即被打开用户自己的等级）；
    若接口未返回该字段则主页不显示等级，不会退化成显示自己的等级。
11. **灵魂鼓点闪光**（默认关闭）：开启后依赖 `android.media.audiofx.Visualizer` 读取播放音频的低频能量，
    需要 `RECORD_AUDIO` 权限（仅本地做频谱分析，不录音、不上传）；拒绝授权或设备不支持时，
    动效自动退回约 125 BPM 的模拟节拍。
    能量处理为「自动增益（按本曲峰值归一化，峰值约 10s 衰减）+ 约 2s 慢基线做**起拍检测**」，
    抬升 0.12 即判定为满格（灵敏度调高），因此不同响度、不同曲风的歌曲都能得到接近满幅的律动；
    切歌后需要先取到封面主色（在线封面要下载），取色完成前背景是主题底色（≈纯黑），
    取色完成后背景色与光晕一起淡入（背景色 460ms 渐变、光晕 150ms 淡入）。
    浅色主题不会被压成黑底白字（光晕会收敛在浅底上做彩色呼吸，文字 / 控件保持深色）。
12. **锁屏 / 通知栏歌词**：Android 13+ 的媒体卡片由 SystemUI 绘制，只认
    「标题 + 一行副标题」，第三方无法自定义布局 / 追加第二行文字，所以实现方式是把
    副标题（歌手位）换成当前歌词；关闭开关后恢复显示歌手名。
    歌词在播放服务里独立加载（不依赖播放页是否打开），每句变化时只刷新会话元数据，
    不替换 ExoPlayer 的媒体项，因此不会重新加载音频 / 卡顿。
    系统卡片宽度不可控，逐句长度差太多会导致卡片高度忽高忽低（看起来一跳一跳），
    因此加载歌词时会按整首歌最长的一句判断行数：全曲统一一行或统一两行，
    长句优先在标点 / 空格处断开，短句用一行空白（全角空格）补齐；两行仍放不下的
    第二行用省略号截断，保证整首歌里每句的显示高度一致。单行安全宽度按
    「16 个汉字」估算，并随系统字体缩放调整（字号越大，一行能放的字越少）。
